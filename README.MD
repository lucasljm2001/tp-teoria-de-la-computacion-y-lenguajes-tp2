# Enunciado
Se requiere la creación de un sistema que permita realizar el control de residuos peligrosos, para lo cual debe generar el código de evaluación de residuos para incorporar al sistema.

El bloque procesará la siguiente información:

Nivel de peligrosidad
Cantidad en kilos
Destino
Se debe considerar validar que la cantidad de kilos a procesar no supero los 450 kilos.

El programa deberá generar un resultado el cual determine que el residuo ha sido procesado o se ha rechazado.
